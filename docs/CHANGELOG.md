# 更新日志

> 历史变更记录｜整理日期：2026-10-08｜依据：原有版本记录，近期能力结合当前源码核对。历史条目不是当前功能或设备兼容性承诺。

开发方向与未完成事项独立维护在[开发计划](ROADMAP.md)。

## 2026-09-20
- 编译器
	- [新增] 通过可选环境变量`LIBRARIES_HOME`加载扩展类库；未设置或目录不存在时只使用Simple运行库
	- [新增] 支持扩展类库固定运行结构，包括`classes.jar`以及可选的`libs`、`res`、`assets`和`jni`目录
	- [新增] 仅将项目实际引用类库的代码、依赖、Android资源、资产和原生库打包到APK
	- [新增] 支持运行库对象使用`@ManifestNodes`向`manifest`、`application`、主`activity`和主`intent-filter`注入Android清单节点
	- [新增] 清单节点支持`${宏名}`和`${宏名=缺省值}`，从`project.properties`的“类简名.宏名”读取配置；缺少必填宏时终止编译
	- [修复] 清单宏替换正确保留宏值中的美元符号和反斜杠

## 2026-09-19

	- [新增] 面板增加绝对布局，支持按坐标定位组件
	- [优化] 面板重复设置相同布局时复用当前布局实例

	- [新增] 增加列表框、下拉列表框、单选列表框、多选列表框、水平与垂直滑块条、水平与垂直滚动框、进度圈、水平进度条、音频播放器、视频播放器、图片按钮、广播接收器、权限请求和网页浏览框组件
	- [新增] 面板增加相对布局
	- [新增] 增加对话框、事件、像素、资源、资产、编码、程序、线程、加密、颜色和JSON操作函数集

## 2026-09-08
- 编译器
	- [新增] 使用AAPT2生成`R.txt`和标准分层`R.java`，编译生成的`R.class`及`R$*.class`可供Android代码和第三方依赖使用
	- [新增] 将`R.txt`转换为内存中的`SimpleResources.simple`并生成应用包下的`SimpleResources.class`，避免与Android标准`R`类及用户单元名称冲突
	- [新增] 将当前应用的`SimpleResources`以全局名称`R`公开，任意命名空间的Simple单元均可直接使用`R.xxx`，无需声明别名或书写完整限定名
	- [优化] 资源编译、索引生成和最终打包共用稳定资源编号，相关中间文件统一输出到`build\res`
- 运行库
	- [变更] 将消息处理组件调整为消息传递器，使用消息标记和变体型载荷传递跨线程消息
