# 窗口设计

> 使用指南｜核对日期：2026-10-08｜依据：当前扩展源码、SDK 清单与真实 Simple 样例｜适用范围：当前 ES4A SDK 与 VS Code 扩展。

## 打开与选择组件

在项目树中右键窗口单元，选择 **设计窗口布局**。设计器只支持窗口；对象、接口和服务在代码中编辑。

设计器标签页包含“可用”组件、布局树、画布、启用的非可视组件和属性区。先在布局树或画布中明确选中组件，再修改属性。ES4A 侧边栏的“类库”视图用于查阅 API，不是拖入组件的工具箱。

## 添加与管理

- 从“可用”区把可视组件拖入窗口或面板等容器；非可视组件拖入“启用”区。
- 组件名称用于代码引用，必须有效且在该单元内唯一。文本或标题属性是显示内容，不是代码名称。
- 在布局树和组件菜单中完成新增、复制、粘贴、移动、改名与删除，再保存设计器。
- 选择事件菜单项时，已有事件会跳转到主体；缺少事件则插入处理过程，在代码标签中编辑并保存。

新增组件不意味着把所有缺省属性写入文件。属性区显示实际设置值或缺省值；清除显式设置后返回缺省显示。不要根据属性框显示值推断文件中存在相应赋值。

## 布局选择

Simple 没有独立布局节点。窗口是根容器，面板等容器通过自己的 `布局` 属性排列子组件；布局的方向、对齐、行列等设置随布局类型显示。

| 布局 | 常见用途 |
| --- | --- |
| 线性布局 | 水平或垂直顺序排列，可按权重分配剩余空间 |
| 表格布局 | 按行列放置，先确定行列数，再放子组件 |
| 单帧布局 | 叠放组件，后加入的组件位于上层 |
| 相对布局 | 相对父级或直接可视兄弟定位 |
| 绝对布局 | 按左边、顶边坐标定位固定界面 |

相对布局中锚点只能选直接可视兄弟，选择后写入该兄弟的标识引用。组件自身对齐与内部内容对齐不同；切换父级布局后，不适用的已有属性值仍保留。

## 尺寸和预览边界

设计面固定为 `480×800 DIP`，用于低保真布局检查。`长度_适应内容`（`-1`）按内容收缩，`长度_匹配父级`（`-2`）填满父容器，非负整数表示固定 DIP。属性输入还可使用 `30dp` 等单位文本。

设计器不执行 Simple 表达式，对其他表达式不求值、不改写。设备的主题、字体、分辨率、Android 版本和真实组件实现会影响最终效果。只能用设备运行确认像素效果和事件行为。

## 保存与检查

设计器的保存、撤销、重做作用于组件属性；代码标签独立保存用户代码。关闭前检查两侧的未保存标记。设计器保存保留磁盘上的用户代码，代码保存保留磁盘上的组件属性；冲突提示出现时先确认外部变更，再处理。

本页介绍当前支持的操作，组件的属性、函数和事件在[核心 API](api/README.md)及[扩展类库使用](libraries/README.md)中查询。
