# 应用开发常见问题

> 使用指南｜核对日期：2026-10-08｜依据：当前扩展源码、SDK 清单与真实 Simple 样例｜适用范围：当前 ES4A SDK 与 VS Code 扩展。

## 没有 SDK 或类库为空

执行 **ES4A: 选择 SDK**，选根目录 `sdk.json`；路径已移动时重新选择。然后执行 **刷新类库**，按提示检查缺失文件。应用开发者使用完整 SDK，无需编辑类库定义。

## 找不到类库类型或成员

先确认选择了正确 SDK，再查[扩展类库查阅方法](libraries/README.md#查阅与准备)。扩展类型一般先用完整限定名建立别名，普通对象需创建实例，组件在窗口设计器中添加。不要把静态函数、实例函数和全局函数混用。

## 界面有补全，但编译失败

补全来自 SDK 元数据，编译来自真实代码。先看正式编译错误，检查发行 SDK 的代码和说明是否属于同一版本；只看到类库树不能证明实际代码完整。

## 编译提示缺少 Java、Android 工具或核心 JAR

按[环境准备](tutorial/environment.md)检查文件和解压层级。当前能力脚本依赖固定的 SDK 工具位置，安装任意新版工具不一定兼容。

## 按钮事件不触发或组件没出现

检查设计器是否保存、事件拥有者是否与组件名称一致、是否使用了对应组件的事件名。核心按钮事件为 `被单击`；创建一个普通对象并不等于向窗口添加组件。

## 设计器与手机效果不同

设计器是固定尺寸的低保真投影，不运行表达式，也不执行组件代码。用[窗口设计](tutorial/designer.md)检查容器、尺寸与布局，再在目标设备确认真实效果。

## 代码或设计器保存提示冲突

检查文件是否被外部程序修改，以及两侧标签是否有未保存内容。不要反复强制覆盖；保留需要的代码和属性后重新加载。两个标签的保存状态独立。

## 资源 R 中没有成员

确认文件放在有效 Android 资源目录、名称合法且资源编译已成功。`R` 指向当前应用的 Simple 资源对象，资产文件不自动产生 Android 资源编号。

## 安装失败、应用没启动或权限未授予

按[安装与启动](tutorial/build.md#安装与启动)检查 ADB 授权和设备连接。权限声明不等于运行时授权；按对应 API 的要求请求权限并处理拒绝。某些类库功能还受设备系统设置影响，按所用版本的要求核对。

## 重命名后旧类型还出现

当前编译流程可能保留旧的生成类。确认只是构建输出后清理该项目 `build` 再编译，保留 `src`、`assets` 与 `res`。这个问题列入[开发计划](ROADMAP.md)，不能据此认为已修复。
