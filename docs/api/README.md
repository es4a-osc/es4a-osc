# 核心 API 使用

> 使用指南｜核对日期：2026-10-08｜依据：当前运行库公开注解、编译器名称解析与 ES4A 类库视图｜适用范围：Simple 应用开发。

本页说明如何查阅和调用核心运行库。具体组件、对象、函数集与成员以你选择的 SDK 为准，不在网站另列一份类型和成员目录。语言写法见[Simple 语法参考](simple/Simple语言定义.md)。

## 查阅所用 SDK

先[选择 SDK](tutorial/environment.md#选择-sdk)，再打开 ES4A 侧边栏的“类库”视图，展开运行库及其分类、类型和成员。编写代码时结合成员补全、悬停说明和参数提示，确认完整类型名、参数顺序、返回值及继承成员。

未在该 SDK 中提供的类型或成员，不能因为别的版本有过就直接使用。代码提示来自元数据，正式可调用性仍以编译结果为准。

## 使用组件

在[窗口设计器](tutorial/designer.md)添加组件，用组件名称引用；可视组件放入窗口或容器，非可视组件在设计器启用。普通对象和函数集不作为组件拖入。

通过组件实例读取或设置属性、调用函数。事件从设计器的组件事件菜单生成或定位处理过程，事件名和参数使用所用 SDK 的定义。具体操作见[快速入门](tutorial/started.md)。

## 使用对象与函数集

普通对象按其公开用法声明变量，在允许自行创建时用 `创建 类型` 取得实例，再调用实例成员。由其他 API 返回的对象按返回值使用，不假定每个对象都有可直接调用的无参构造。

已公开为全局函数的核心成员直接按名称调用。类型成员通过类型调用，实例成员通过实例调用；函数集的分类名称本身不是需要创建的对象。根据成员说明选择调用方式，不把它们混用。

## 读取成员说明

调用前确认参数的类型、顺序、传值或传址方式，以及返回值。只读属性不能赋值，只写属性不能读取；继承成员也需要符合其声明。

文件路径、资产名称与 Android 资源编号是不同输入，按具体成员的参数要求使用。事件回调、线程、权限与生命周期要求也应根据所用成员核对，不能用 IDE 提示代替设备验证。

语法细节见[函数声明](simple/Simple语言定义.md#函数声明)与[过程声明](simple/Simple语言定义.md#过程声明)及[事件处理声明](simple/Simple语言定义.md#事件处理声明)，资源组织见[项目操作](tutorial/project.md#资源与资产)。

## 更新与排查

更新 SDK 后刷新类库，重新核对本项目使用的成员并[正式编译](tutorial/build.md)。补全与编译不一致时先检查 SDK 入口、元数据和实际代码是否属于同一版本，见[常见问题](tutorial/faq.md#界面有补全但编译失败)。

源码核对可从[Simple 源码仓库](https://gitee.com/es4a/simple)与[SDK 仓库](https://gitee.com/es4a/sdk)进入；使用历史版本时选择对应版本，不把主分支当作所有发行版本的说明。
