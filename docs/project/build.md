## 编译应用

1. 保存代码和设计器中的修改。
2. 在 ES4A 项目树上右键项目，选择 **编译应用**。
3. 查看自动打开的终端，确认编译成功。

APK 默认生成在项目的 `build/deploy/` 目录，文件名为应用名称。编译失败时先处理终端报告的错误，再重新编译。

## 安装与启动

1. 连接 Android 设备，启用 USB 调试，并接受设备上的电脑授权。
2. 在项目上右键，选择 **调试应用**。
3. 等待编译、安装和启动完成，在设备上测试应用。

“调试应用”会自动执行上述流程，当前不提供断点、单步和变量查看。连接多个设备时，先只保留本次运行的设备。

## 应用签名

默认使用调试签名，当前菜单未提供发布签名配置。正式发布前需要准备发布签名，并确认 APK 的实际签名。

编译失败时按终端的文件和行号处理错误；工具、资源或安装问题见[常见问题](project/faq.md)。
