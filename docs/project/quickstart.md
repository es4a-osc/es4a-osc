# 快速入门：第一个按钮应用

<!-- 文档信息：使用指南｜核对日期：2026-10-09｜依据：当前扩展源码、SDK 清单与真实 Simple 样例｜适用范围：当前 ES4A SDK 与 VS Code 扩展。 -->

目标是在手机上单击按钮，显示“你好，Simple”。先完成[环境准备](project/environment.md)，再按以下步骤操作。

## 创建项目

1. 打开 ES4A 侧边栏，在“项目”标题栏点击 **创建项目**。
2. 选择项目的上级保存目录。
3. 输入项目目录名，例如 `HelloSimple`；这个目录必须尚不存在。
4. 输入应用包名 `com.example.hello`。
5. 输入应用显示名称“你好 Simple”。

创建后项目加入“项目”视图，主窗口代码自动打开。

包名至少两段，每段以英文字母开头，只含英文字母、数字与下划线。应用名称可以使用中文，它与项目目录名、包名是三个不同值。

## 添加按钮

1. 在项目树中右键“主窗口”，选择 **设计窗口布局**。
2. 在设计器“可用”区找到运行库中的“按钮”，拖入窗口。
3. 在布局树中选择按钮，把组件名称设为 `按钮1`，文本设为“打招呼”。
4. 右键该组件，从“组件事件”选择 **被单击**，生成或定位事件处理过程。
5. 在代码事件体中填写：

```simple
事件 按钮1.被单击()
	显示提示框("你好，Simple")
结束 事件
```

只填写事件体；已有声明时不要再嵌套一份 `事件 … 结束 事件`。按钮的显示内容通过 `文本` 属性设置。

## 保存、编译与运行

分别保存代码和设计器标签页中的实际修改。在项目树上执行 **编译应用**，从终端输出检查编译是否成功。默认 APK 位于 `build/deploy/你好 Simple.apk`。

连接已授权的 Android 设备后执行 **调试应用**。扩展自动编译、安装并启动应用。手机上单击按钮，应出现提示文字。

## 下一步

继续阅读[项目操作](project/operations.md)和[窗口设计](project/designer.md)。如果按钮没出现，检查设计器是否保存；如果编译失败，先看终端的第一条正式错误，再查[常见问题](project/faq.md)。
