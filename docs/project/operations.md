## 添加与管理项目

在 ES4A“项目”标题栏点击 **添加项目**，选择已有项目中的入口文件 `project.properties`。新项目通过 **创建项目** 生成，步骤见[快速入门](project/quickstart.md)。

- **刷新项目**：重新读取项目。
- **移除项目**：从列表移出，保留文件。
- **删除项目**：删除项目目录，按提示选择回收站或永久删除。

## 创建与组织单元

在“单元”或单元文件夹上右键，创建窗口、对象、接口、服务或文件夹。窗口用于界面，其他单元用于代码；线程使用对象与线程 API。

通过项目树改名或在同一项目内拖动单元，扩展会同步受影响的引用。跨项目拖动不支持；主单元移动可能改变应用包名，按提示确认。

## 应用属性

右键项目，选择 **编辑属性**：

| 菜单 | 操作 |
| --- | --- |
| 应用名称 | 输入手机上显示的名称 |
| 版本号 | 输入大于或等于 1 的整数 |
| 版本名 | 输入显示用的版本文字 |
| 应用图标 | 选择已导入的 drawable 或 mipmap 资源 |
| 屏幕方向 | 选择默认、横向或纵向 |
| 应用主题 | 选择预设主题，或输入自定义主题 |
| 清单宏… | 按类库说明添加或修改宏名称和值 |

扩展自动保存这些设置。类库要求额外配置时，按对应版本的说明操作，见[扩展库](project/extensions.md)。

## 资源与资产

在项目树的资源分类或目录上右键，选择 **导入资源**，按对话框选择文件。应用图标先导入 drawable 或 mipmap，再通过“编辑属性 → 应用图标”选择。

Android 资源编译后可通过 `R` 引用，例如 `R.drawable_icon`；资产是原样打包的文件。项目树可复制资源索引、文件名或相对路径，按所调用 API 的要求使用。

布局和事件操作见[窗口设计](project/designer.md)，保存后按[编译与运行](project/build.md)测试应用。
