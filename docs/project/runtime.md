运行库随 SDK 提供组件、对象和函数，具体成员以所选版本为准。

## 查阅与调用

在 ES4A“类库”视图展开运行库，结合补全、悬停和参数提示查阅成员、参数与返回值。

- **组件**：在[窗口设计器](project/designer.md)添加，通过组件名称读写属性、调用函数，并从事件菜单生成处理过程。
- **普通对象**：按成员说明取得实例；允许自行创建时使用 `创建 类型`，通过实例调用成员。
- **静态成员**：通过类型调用；运行库中已公开为全局函数的成员也可直接按名称调用。
- **分类**：类库树中的分类用于浏览，不作为对象创建。

名称和调用规则见[Simple 语法](project/syntax.md)；实际操作示例见[快速入门](project/quickstart.md)。

## 使用注意

确认参数的类型、顺序、传值或传址方式，以及属性是否可读写。文件路径、资产名称与 Android 资源编号按成员要求使用，资源操作见[项目操作](project/operations.md#资源与资产)。

权限、线程、回调与生命周期要求按成员说明处理，在设备上验证所用功能。更新 SDK 后[刷新类库](project/environment.md#选择-sdk)并重新编译；提示与编译不一致时查看[常见问题](project/faq.md#界面有补全但编译失败)。
