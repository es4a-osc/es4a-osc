常见问题

关于 Simple、开发准备与应用运行。

ES4A 和 Simple 是什么关系？

Simple 是面向 Android 的中文 BASIC 方言，以组件和事件组织应用。ES4A 是配套的 VS Code 扩展，提供代码编辑、项目管理和窗口设计；SDK 提供编译器、运行库、扩展库及工具。

开始开发需要准备什么？
  1. 在 Windows 上下载安装 Visual Studio Code。
  2. 下载 ES4A 扩展，在 VS Code 扩展面板选择“从 VSIX 安装”。
  3. 下载并解压 SDK，按其中的 README 准备工具，再在 ES4A 类库视图中选择该 SDK 的 sdk.json。
开发应用需要先学 Java 吗？

应用逻辑使用 Simple 编写，调用现有运行库和扩展库不要求编写 Java。自行开发扩展库、封装新的对象或组件时，才需要编写相应的 Java 实现。

怎么把应用运行到手机上？

为 Android 设备开启 USB 调试，连接电脑并允许调试授权。配置好 SDK 后，可从 ES4A 项目菜单发起编译；“调试应用”会编译、安装并启动应用，当前不提供断点和单步调试。

可以复用 Java 类库吗？

可以通过扩展库复用 Java 实现。需要按 Simple 类库规则封装对象或组件，并定义对应清单；普通 JAR 不能仅通过复制到 SDK 就直接在 Simple 中调用。

开发文档在哪里？

文档位于 SDK 的 docs 目录，从 docs/README.md 开始阅读，按项目开发或类库开发查找对应说明。Markdown 文档可供开发者和 AI 查阅。
